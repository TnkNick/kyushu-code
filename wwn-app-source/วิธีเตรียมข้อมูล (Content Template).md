# วิธีเตรียมข้อมูลสำหรับเว็บแผนการเดินทาง

คู่มือนี้อธิบาย **ทุกช่องข้อมูล** ที่เว็บนี้ใช้ พร้อมแบบฟอร์มเปล่าให้กรอก
ข้อมูลทั้งหมดอยู่ในไฟล์เดียวคือ **`data.jsx`** — แก้ที่นี่ที่เดียว เว็บจะอัปเดตตามทันที

> ⚠️ หลังแก้ `data.jsx` แล้ว ต้องคัดลอกเนื้อหาเดียวกันไปวางในบล็อก `data.jsx` ที่ฝังอยู่ในไฟล์ `Japan Trip - App.html` ด้วย (เว็บจริงรันจากไฟล์ HTML) — หรือแจ้งให้ผมช่วยซิงค์ให้

---

## 1. กฎพื้นฐาน 3 ข้อ ที่ต้องเข้าใจก่อน

### 1.1 ทุกข้อความเป็น 2 ภาษา — ใช้ `L('อังกฤษ', 'ไทย')`
ทุกข้อความที่ผู้ใช้เห็นเขียนในรูปแบบ:
```js
L('English text', 'ข้อความภาษาไทย')
```
- ช่องแรก = อังกฤษ, ช่องสอง = ไทย
- ถ้ามีภาษาเดียว ใส่ข้อความเดียวกันทั้งสองช่องได้
- ข้อความที่ **ไม่ใช่** `L(...)` (เช่น `code: 'TG-622'`, ตัวเลข, URL) คือค่าที่เหมือนกันทุกภาษา ไม่ต้องแปล

### 1.2 รูปภาพ — ไม่ต้องใส่ไฟล์ในข้อมูล แต่ "ลากวาง" ในเว็บ
ทุกที่ที่มีรูปจะมี **`imageId`** (เช่น `'a-d1-kikunoi'`) ซึ่งเป็น "ช่องวางรูป" ในเว็บ
- เปิดเว็บ → **ลากไฟล์รูปจากเครื่องไปวางที่ช่องนั้น** → รูปจะถูกบันทึกในเบราว์เซอร์ (อยู่ถาวรแม้รีเฟรช)
- หน้าที่ของคุณในการเตรียมข้อมูล: ตั้งชื่อ `imageId` ให้ไม่ซ้ำกัน + เตรียมไฟล์รูปไว้ลากวางทีหลัง
- **เมนูอาหาร**: รูปอาหารใช้ช่องอัตโนมัติ (id = `dish-<imageId ของร้าน>-<ลำดับ>`) แค่กดเมนูแล้วลากรูปวางใน popup

### 1.3 ค่าที่ "เลือกจากชุดที่กำหนด" (ห้ามพิมพ์มั่ว)
บางช่องต้องใช้ค่าจากรายการที่ระบบรู้จักเท่านั้น — ดูตารางอ้างอิงในหัวข้อ **[ภาคผนวก]** ท้ายเอกสาร:
- `theme` (สีประจำวัน) · `kind` (ประเภทกิจกรรม) · `meridiem` (ช่วงเวลา) · `icon` (ไอคอน)

## 2. ข้อมูลหัวเรื่องทริป — `TRIP` (ส่วนบนสุด)

| ช่อง | ความหมาย | ตัวอย่าง |
|---|---|---|
| `title` | ชื่อประเทศ/ทริป (โชว์ใหญ่) | `L('Japan', 'ญี่ปุ่น')` |
| `subtitle` | คำโปรย | `L('Ten Days Across the Old & New', 'สิบวัน...')` |
| `dates` | ช่วงวันที่ | `L('14 — 23 November 2026', '14 — 23 พฤศจิกายน 2026')` |
| `meta` | ป้ายฤดูกาล/บริบท | `L('Late Autumn · Momiji Season', 'ปลายฤดู...')` |
| `origin` | คำบรรยายสั้น | `L('A private itinerary', 'แผนการเดินทางส่วนตัว')` |
| `days` | รายการวัน (ดูหัวข้อ 3) | `[ {...}, {...} ]` |

## 3. แต่ละวัน — `TRIP.days[]`  ⭐ ส่วนที่ใหญ่ที่สุด

แต่ละวันคือ 1 ออบเจกต์ในอาเรย์ `days`:

```js
{
  label: 'Day 01',            // ป้ายวัน (อังกฤษ) — ต้องมีตัวเลขวัน เช่น "Day 01"
  labelTh: 'วันที่ 01',        // ป้ายวัน (ไทย)
  theme: 'kurogane',          // สีประจำวัน — เลือกจากชุดธีม (ดูภาคผนวก)
  date: L('Friday · 14 November 2026', 'ศุกร์ · 14 พฤศจิกายน 2026'),
  title: L('Higashiyama', 'ฮิงาชิยามะ'),          // ชื่อวัน (โชว์ใหญ่)
  subtitle: L('Arrival & the Eastern Hills', '...'), // คำโปรยใต้ชื่อ
  note: L('คำบรรยายวันแบบยาว...', '...'),          // ย่อหน้าเล่าภาพรวมวัน
  coverId: 'day1-cover',      // imageId รูปปกวัน (ตั้งให้ไม่ซ้ำ)
  activities: [ ... ]          // กิจกรรมในวัน (ดูหัวข้อ 3.1)
}
```

> 📌 `label` **ต้องมีเลขวัน** (เช่น `Day 01`, `Day 02`) เพราะระบบใช้เลขนี้จับคู่ **อากาศ** และ **ร้านสะดวกซื้อ** ของวันนั้นอัตโนมัติ

### 3.1 กิจกรรมในวัน — `activities[]`
มี 2 แบบ เลือกตาม `type`:

#### แบบ A — `type: 'feature'` (สถานที่/ร้านอาหาร — มีรูปใหญ่)
```js
{
  type: 'feature',
  time: '13:30',              // เวลา (โชว์ตรงๆ)
  meridiem: 'Midday',         // ช่วงเวลา — เลือกจากชุด (ดูภาคผนวก)
  kind: 'Dining',             // ประเภท — เลือกจากชุด (ดูภาคผนวก)
  imageId: 'a-d1-kikunoi',    // ช่องรูป (ตั้งให้ไม่ซ้ำ) — แนะนำรูปแบบ a-d<วัน>-<ชื่อย่อ>
  title: L('Kikunoi Roan', 'คิคุโนอิ โรอัน'),
  place: L('Kaiseki · Kiyamachi', 'ไคเซกิ · คิยามาจิ'),  // สถานที่/ประเภทย่อย
  blurb: L('คำบรรยายกิจกรรม...', '...'),
  refs: { ... }               // ข้อมูลอ้างอิง/การจอง (ดูหัวข้อ 3.2) — ใส่เท่าที่มี
}
```

#### แบบ B — `type: 'step'` (โลจิสติกส์ — แถวเล็ก มีไอคอน)
ใช้กับ เที่ยวบิน / รถไฟ / เช็คอิน / ตั๋ว ฯลฯ
```js
{
  type: 'step',
  time: '08:46',
  meridiem: 'Morning',
  kind: 'Train',              // ประเภท — เลือกจากชุด
  icon: 'train',              // ไอคอน — เลือกจากชุด (ดูภาคผนวก)
  title: L('Haruka Express → Kyoto', 'รถไฟด่วน Haruka → เกียวโต'),
  place: L('KIX → Kyoto Stn · 80 min', 'KIX → สถานีเกียวโต · 80 นาที'),
  blurb: L('คำบรรยาย...', '...'),
  refs: { ... }               // ใส่เท่าที่มี
}
```
> `step` ไม่มีรูป จึงไม่ต้องมี `imageId` แต่ต้องมี `icon`

### 3.2 ข้อมูลอ้างอิง/การจอง — `refs: { }`
ใส่เฉพาะคีย์ที่มีข้อมูล (ทุกคีย์เป็นทางเลือก) — คีย์เหล่านี้ยังไปโผล่ในหน้า **"การจอง"** อัตโนมัติด้วย:

| คีย์ | ความหมาย | รูปแบบค่า |
|---|---|---|
| `map` | ลิงก์แผนที่ | `'https://maps.google.com/?q=...'` |
| `official` | เว็บไซต์ทางการ | `'https://...'` |
| `guide` | ลิงก์ไกด์ท้องถิ่น | `'https://...'` |
| `reservation` | การสำรองที่นั่ง/ห้อง | `{ time: '13:30', code: 'KNR-22184', party: L('โต๊ะ 2 ท่าน','...') }` |
| `booking` | ค่าใช้จ่าย/ตั๋วที่จ่ายแล้ว | `L('Prepaid · ¥11,000 pp', 'ชำระล่วงหน้า...')` |
| `notes` | บันทึกเพิ่มเติม | `L('แต่งตัวสุภาพ...', '...')` |

> หน้า **"การจอง"** จะรวมทุกกิจกรรมที่มี `reservation` (เป็นการ์ดติ๊กได้) และทุกอันที่มี `booking` (เป็นรายการตั๋ว/ค่าเข้า)

### 3.3 เมนูอาหารแนะนำ — `MENUS` (สำหรับร้านอาหาร)
แยกอยู่อีกบล็อก (ดูหัวข้อ 11) จับคู่กับร้านด้วย **`imageId`** ของกิจกรรมนั้น

## 4. หน้าภาพรวม + แผนที่เส้นทาง — `DESTINATION`

```js
const DESTINATION = {
  island: L('Honshu', 'ฮอนชู'),         // ชื่อเกาะ/ภูมิภาคใหญ่ (โชว์ใหญ่บน hero)
  islandNative: '本州',                  // อักษรท้องถิ่น (ลายน้ำ)
  country: L('Japan', 'ญี่ปุ่น'),
  native: '日本',
  tagline: L('คำโปรยหน้าแรก...', '...'),
  facts: [                              // การ์ดข้อเท็จจริง 4 ช่อง
    { k: L('Duration','ระยะเวลา'), v: L('10 days · 9 nights','10 วัน · 9 คืน') },
    { k: L('Season','ฤดูกาล'),     v: L('Late autumn · momiji','...') },
    // ... ใส่กี่อันก็ได้
  ],
  route: [ ... ]                        // หมุดบนแผนที่ (ดูหัวข้อ 4.1)
};
```

### 4.1 หมุดบนแผนที่เส้นทาง — `route[]`
แต่ละหมุดคือ 1 เมือง วางบนแผนที่ตามพิกัด `mx`/`my`:

| ช่อง | ความหมาย | ตัวอย่าง |
|---|---|---|
| `city` | ชื่อเมือง | `L('Kyoto','เกียวโต')` |
| `days` | ช่วงวันที่อยู่เมืองนี้ | `L('Days 1–3','วันที่ 1–3')` |
| `day` | **ดัชนีวันแรก** ของเมืองนี้ (เริ่มจาก 0) | `0` = วันที่ 1, `3` = วันที่ 4 |
| `theme` | สีประจำเมือง | `'kurogane'` |
| `imageId` | ช่องรูปวงกลมของหมุด | `'r-kyoto'` |
| `mx` | ตำแหน่งแนวนอน 0–100 (ซ้าย→ขวา) | `25` |
| `my` | ตำแหน่งแนวตั้ง 0–100 (บน→ล่าง) | `28` |

> `mx`/`my` วางตามภูมิศาสตร์จริง: ฝั่งตะวันตก = ค่า mx น้อย, ตะวันออก = mx มาก
> เส้นทางบนแผนที่จะลากเชื่อมหมุด **ตามลำดับในอาเรย์**

## 8. ร้านสะดวกซื้อ — `KONBINI` (โชว์บนหัวแต่ละวัน)

จัดกลุ่มตาม **โซนที่พัก** แต่ละโซนใส่ได้หลายร้าน ระบบจับคู่กับวันด้วยเลขใน `days`:

```js
const KONBINI = {
  title: L('Konbini Near Each Stay','ร้านสะดวกซื้อใกล้ที่พัก'),
  subtitle: L('24-hour convenience stores','...'),
  note: L('...','...'),
  areas: [
    {
      days: L('Day 01–02','วันที่ 01–02'),     // ⭐ ต้องมีเลขวัน — ใช้จับคู่กับวัน
      area: L('Gion · Higashiyama','กิออน · ฮิงาชิยามะ'),  // ชื่อโซน
      stores: [
        { brand: '7-Eleven', detail: L('Higashiyama-dori · ~150 m','ถนนฮิงาชิยามะ · ~150 ม.'),
          map: 'https://maps.google.com/?q=7-Eleven+Gion+Kyoto' },
        // ... ใส่กี่ร้านก็ได้
      ]
    },
    // ... 1 โซน/ช่วงวัน ครอบคลุมให้ครบทุกวัน
  ]
};
```
> เลขใน `days` ของแต่ละโซนต้อง **ครอบคลุมทุกวัน** เช่น `Day 01–02`, `Day 03`, `Day 04–05` ...

## 9. พยากรณ์อากาศ — `WEATHER` (โชว์บนหัวแต่ละวัน)

จับคู่ด้วย **เลขวัน** (key `1`–`10` ตามจำนวนวัน):

```js
const WEATHER = {
  note: L('สภาพอากาศโดยทั่วไป...','...'),
  days: {
    1:  { icon: 'cloudSun', hi: 17, lo: 8, label: L('Mild, partly cloudy','อากาศดี มีเมฆบางส่วน') },
    2:  { icon: 'sun',      hi: 18, lo: 8, label: L('Clear autumn day','...') },
    // ... ครบทุกวัน
  }
};
```
| ช่อง | ความหมาย |
|---|---|
| `icon` | ไอคอนอากาศ — ใช้ `'sun'`, `'cloudSun'`, หรือ `'cloud'` |
| `hi` / `lo` | อุณหภูมิสูง/ต่ำ (ตัวเลข องศา C) |
| `label` | คำบรรยายสภาพอากาศ |

## 11. เมนูอาหารแนะนำ — `MENUS`

จับคู่กับร้านด้วย **`imageId`** ของกิจกรรมร้านอาหารนั้น (ต้องตรงกันเป๊ะ):

```js
const MENUS = {
  'a-d1-kikunoi': {                  // ← imageId ของกิจกรรมร้านนี้
    items: [
      { name: L('Matsutake dobin-mushi','โดบินมุชิ...'),
        note: L('คำอธิบายเมนูสั้นๆ','...'),
        signature: true },           // true = ติดป้าย "เมนูเด่น" (ใส่เฉพาะเมนูเด็ด)
      { name: L('...','...'), note: L('...','...') },
      // ... 3–4 เมนู/ร้าน
    ]
  },
  // เพิ่มร้านอื่นด้วย imageId ของมัน
};
```
> รูปอาหาร: กดเมนูในเว็บ จะเปิด popup ให้ **ลากรูปวาง** (ช่องรูปสร้างอัตโนมัติ ไม่ต้องตั้ง id เอง)

# 📎 ภาคผนวก — ตารางค่าที่เลือกได้

### A. ธีมสีประจำวัน — `theme`
ใช้ได้ 6 สี (โทนเข้มสไตล์ญี่ปุ่น):
`kurogane` (ดำเหล็ก) · `hisui` (เขียวหยก) · `urushi` (แดงเลือดหมู) · `ai` (น้ำเงินคราม) · `kohaku` (เหลืองอำพัน) · `botan` (ชมพูโบตั๋น)

### B. ประเภทกิจกรรม — `kind`
ค่าที่มีคำแปลไทยอัตโนมัติ (ใช้ค่าอื่นได้ แต่จะไม่แปลไทย):
- **สถานที่ (feature):** `Coffee` `Temple` `Dining` `Wander` `Garden` `Grove` `Journey` `Park` `Shrine` `Castle` `Market` `View` `Lake` `Ferry` `Nightlife`
- **โลจิสติกส์ (step):** `Flight` `Immigration` `Ticket` `Train` `Shinkansen` `Bus` `Transfer` `Walk` `Check-in` `Check-out` `Onsen` `Departure` `Arrival`

### C. ช่วงเวลา — `meridiem`
`Pre-dawn` · `Dawn` · `Morning` · `Late morning` · `Midday` · `Afternoon` · `Evening` · `Night`

### D. ไอคอน — `icon` (สำหรับ step และ EMERGENCY)
`plane` `train` `car` `walk` `bed` `passport` `luggage` `ticket` `book` `clock` `compass` `pin` `map` `phone` `wallet` `bowl` `store` `sun` `cloud` `cloudSun` `note` `alert` `plus` `feather` `calendar` `external` `link`

### E. ประเภทใน `refs` (มีให้แล้ว ไม่ต้องตั้งเอง)
`map` · `official` · `guide` · `booking` · `reservation` · `notes`
